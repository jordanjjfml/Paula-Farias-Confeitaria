# 🎂 Paula Farias Confeitaria

> Status do Projeto: 🚀 Concluído / Em Desenvolvimento (Escolha uma opção)

O site **Paula Farias Confeitaria** é uma plataforma institucional e catálogo digital desenvolvida para apresentar a variedade de doces e salgados artesanais da confeitaria, conectando diretamente os clientes de Manaus ao negócio de forma simples e intuitiva.

🔗 **[Acesse o projeto online aqui](https://jordanjjfml.github.io/Paula-Farias-Confeitaria/)**

---

## 💻 Sobre o Projeto

O objetivo principal deste projeto foi criar uma vitrine virtual atraente e responsiva para a confeitaria. O site permite que os usuários conheçam a história da marca, naveguem por um carrossel interativo de produtos (como bolos caseiros, docinhos de festa e salgados) e iniciem um atendimento personalizado via WhatsApp.

### ✨ Funcionalidades

- **Design Responsivo:** Adaptado perfeitamente para dispositivos móveis, tablets e computadores.
- **Carrossel Interativo:** Navegação fluida para visualização do catálogo de produtos.
- **Chamada para Ação (CTA):** Botões estratégicos direcionando o usuário diretamente para o WhatsApp do negócio para a realização de pedidos.
- **Seções Institucionais:** Áreas dedicadas para apresentar a história da confeitaria ("Sobre Nós") e informações de contato.

---

## 🛠️ Tecnologias Utilizadas

As seguintes ferramentas e tecnologias foram aplicadas na construção deste projeto:

- **HTML5:** Estruturação semântica de todo o conteúdo do site.
- **CSS3:** Estilização, design responsivo, gerenciamento de cores e layout.
- **JavaScript:** Responsável pela lógica do carrossel de produtos e interatividade da página.
- **GitHub Pages:** Hospedagem direta e gratuita do site a partir do repositório.

## 🚀 Como Executar o Projeto Localmente

Se você deseja clonar o projeto e executá-lo em sua máquina local, siga os passos abaixo:

   ```bash

   ```

2. **Navegue até a pasta do projeto:**
   ```bash
   cd Paula-Farias-Confeitaria
   ```

3. **Abra o arquivo principal:**
   Basta dar um duplo clique no arquivo `index.html` ou abri-lo utilizando a extensão *Live Server* no seu VS Code.
